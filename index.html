User Management

All your Ameyo users with their role, plus how many campaigns and lists each one has. Read-only.
⚙ Connect the Ameyo User Management list (all users + roles)
In Ameyo open User → Users, press F12 → Network → Fetch/XHR, reload the list, right-click the request that returns the users and choose Copy → Copy as cURL. Paste it here. The Session ID from the left card is used automatically. Or upload an Excel/CSV with User ID, User Name and User Role columns.

Activity Logs
